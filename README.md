کاریابی · محصولات و خدمات · معرفی کانال‌های واتساپ و تلگرام

## ویژگی‌های نسخه نهایی

- صفحه آغازین متحرک با «بسم‌الله» (فقط یک‌بار با `localStorage`)
- لوگوی رسمی KabulWeb
- بخش کاریابی با جستجو و فیلتر شهر
- بازار محصولات و خدمات
- معرفی کانال‌های واتساپ و تلگرام
- فرم ثبت تبلیغات (آماده اتصال به Supabase)
- صفحه حساب کاربری (ورود / ثبت‌نام)
- طراحی RTL کامل، تم تیره طلایی، واکنش‌گرا
- بدون ریدایرکت و بدون کد آزمایشی

## ساختار فایل‌ها

```
index.html          صفحه اصلی
style.css           طراحی و انیمیشن
script.js           تعاملات و صفحه آغازین
account.html        حساب کاربری
kabulweb-logo.jpg   لوگو
README.md           این فایل
```

## نصب روی GitHub Pages

1. همه فایل‌ها را در ریشه ریپازیتوری قرار دهید
2. Settings → Pages → Source: Deploy from branch → main
3. سایت در آدرس `https://USERNAME.github.io/KabulWeb` در دسترس خواهد بود

## اتصال Supabase (مرحله بعد)

1. پروژه رایگان در [supabase.com](https://supabase.com) بسازید
2. جداول پیشنهادی:
   - `ad_requests` (type, title, description, link, contact, status, user_id, created_at)
   - `job_posts`
   - `listings`
   - `admins`
3. Auth را با ایمیل فعال کنید
4. RLS را طوری تنظیم کنید که فقط آگهی‌های تأییدشده عمومی دیده شوند
5. کلید `anon` را در `script.js` قرار دهید (هرگز `service_role` را در فرانت نگذارید)

## امنیت

- کاربران عادی فقط آگهی‌های تأییدشده را می‌بینند
- تغییر وضعیت به «تأییدشده» فقط از طریق پنل مدیریت و با بررسی سمت سرور
- کلید محرمانه سرویس هرگز در فایل‌های عمومی قرار نمی‌گیرد
