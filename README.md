# کابل‌وب (KabulWeb)

بازار دیجیتال افغانستان و جهان — کاریابی، محصولات و خدمات، معرفی کانال‌های واتساپ و تلگرام.

## ویژگی‌ها

- صفحه آغازین متحرک با بسم‌الله (فقط یک‌بار با localStorage)
- لوگوی رسمی KabulWeb
- بخش کاریابی، بازار، کانال‌ها و ثبت تبلیغات
- حساب کاربری جداگانه
- طراحی RTL، واکنش‌گرا، تم تیره طلایی
- آماده برای GitHub Pages + Supabase

## فایل‌ها

| فایل | توضیح |
|------|--------|
| index.html | صفحه اصلی |
| style.css | طراحی |
| script.js | تعاملات |
| account.html | حساب کاربری |
| kabulweb-logo.jpg | لوگو |

## اجرا

1. همه فایل‌ها را در ریشه ریپازیتوری قرار دهید
2. GitHub Pages را روی branch main فعال کنید
3. سایت آماده است

## مراحل بعدی

- اتصال Supabase (Auth + جداول ad_requests, job_posts, listings)
- پنل مدیریت (admin.html)
- تأیید آگهی‌ها با RLS
