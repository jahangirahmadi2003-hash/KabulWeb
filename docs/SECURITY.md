# وضعیت امنیت کابل‌وب

## بررسی چرخه فعلی (2026-11-13)

### نقاط قوت (در کد مخزن)
- فقط کلید publishable در کلاینت (`js/supabase.js`)
- اجبار `status="pending"` در همه insertها
- `escapeHtml` و بررسی URL ایمن (`isSafeHttpUrl`) در رندر کارت‌ها
- Content-Security-Policy روی صفحه اصلی
- فیلد honeypot در فرم ثبت آگهی + رد سایلنت ربات‌ها
- cooldown کلاینتی 60 ثانیه برای فرم
- چک ادمین با ایمیل + RPC `is_kabulweb_admin` (کد آماده)
- SQL RLS کامل در `docs/security_rls.sql`
