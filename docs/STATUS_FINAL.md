# وضعیت نهایی کابل‌وب — نسخه تکمیل‌شده

## فایل‌های این بسته (جایگزینی)

| مسیر در مخزن | توضیح |
|--------------|--------|
| `js/supabase.js` | توابع آگهی با user_id + پشتیبانی کامل |
| `account.html` | داشبورد حرفه‌ای کاربر |
| `admin.html` | پنل مدیر + تب پشتیبانی |
| `docs/support_and_security_update.sql` | مهاجرت SQL (مرجع؛ قبلاً در Supabase اجرا شده) |

فایل‌های قبلی (`index.html`, `script.js`, `style.css`, `docs/security_rls.sql` و …) **بدون تغییر** حفظ شوند.

## ترتیب اجرا در Supabase

1. اگر هنوز اجرا نشده: `docs/security_rls.sql`
2. سپس: `docs/support_and_security_update.sql` (شما اعلام کردید قبلاً اجرا شده)

## قابلیت‌های واقعی پس از اجرای SQL و فایل‌های این شاخه

- ثبت‌نام / ورود / خروج / بازیابی رمز
- ثبت آگهی با `user_id` (اگر کاربر وارد باشد)
- مشاهده «آگهی‌های من» و وضعیت
- ایجاد تیکت پشتیبانی، پاسخ، بستن
- پنل مدیر: تأیید/رد آگهی‌ها + پاسخ تیکت با RPC امن
- RLS: کاربر نمی‌تواند نقش مدیر یا sender_type=admin جعل کند
